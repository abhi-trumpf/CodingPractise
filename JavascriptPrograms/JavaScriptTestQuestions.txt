-------------------------------------------------------------------
💥 CHALLENGE 1: THE LEGENDARY FIZZBUZZ 
-------------------------------------------------------------------
- The Goal: Run a loop from 1 to 50. 
  * If the number divides by 3 ➡️ Print "Fizz"
  * If the number divides by 5 ➡️ Print "Buzz"
  * If it divides by BOTH 3 and 5 ➡️ Print "FizzBuzz"
  * Otherwise ➡️ Just print the number!
- Test Trap: Check your "if / else if" order! If you check for 3 or 5 
  before checking BOTH, your "FizzBuzz" will never print!

-------------------------------------------------------------------
💥 CHALLENGE 2: THE PALINDROME HUNTER
-------------------------------------------------------------------
- The Goal: Write a function isPalindrome(str) to check if a word is 
  the exact same when flipped backward! 
  * "racecar" ➡️ true
  * "hello"   ➡️ false
- Test Trap: Master your array methods! Try string.split(''), then 
  .reverse(), and then .join('') to see if it matches the original!

-------------------------------------------------------------------
💥 CHALLENGE 3: KING OF THE HILL (FIND MAX NUMBER)
-------------------------------------------------------------------
- The Goal: Take this array: [23, 77, 1, 45, 99, 12]. Find the biggest 
  number WITHOUT using Math.max().
- Test Trap: Make sure you initialize 'let max = arr[0]' BEFORE the 
  loop starts, then update it line-by-line as you step through!

-------------------------------------------------------------------
💥 CHALLENGE 4: VOWEL SMASHER
-------------------------------------------------------------------
- The Goal: Count every single vowel (a, e, i, o, u) inside the string 
  "interview preparation".
- Test Trap: Case sensitivity! Use .toLowerCase() first so capital 
  letters don't break your count tracker!

-------------------------------------------------------------------
💥 CHALLENGE 5: DE-DUPLICATE DESTROYER
-------------------------------------------------------------------
- The Goal: Take [1, 2, 2, 3, 4, 4, 5] and crush it down into a clean 
  array with zero repeating numbers: [1, 2, 3, 4, 5].
- Test Trap: They WANT to see if you know how to use 'new Set(arr)' 
  or the .filter() method. Try typing both!

-------------------------------------------------------------------
💥 CHALLENGE 6: THE FACTORIAL ACCUMULATOR
-------------------------------------------------------------------
- The Goal: Calculate the factorial of 5 (5 * 4 * 3 * 2 * 1 = 120).
- Test Trap: Use a multiplying loop that decrements down to 1. Don't 
  let your tracker variable start at 0 or your whole answer becomes 0!

-------------------------------------------------------------------
💥 CHALLENGE 7: THE TOTAL ACCUMULATOR (.REDUCE)
-------------------------------------------------------------------
- The Goal: Sum up all the numbers in an array.
- Test Trap: Do it with a normal 'for' loop first, but then practice it 
  using 'arr.reduce((total, num) => total + num, 0)'. Freshers who know 
  .reduce() stand out instantly!

## 🧱 Category 1: The String Manipulators

*Professors love these because strings are just arrays of characters in disguise.*

1. **Reverse a String**
* *The Quest:* Take `"hello"` and turn it into `"olleh"`. (You already killed this boss!)


2. **Palindrome Checker**
* *The Quest:* Check if a string reads the same backward as forward (`"racecar"` $\rightarrow$ `true`). (You mastered this one too!)


3. **FizzBuzz** (The most famous filter question in history)
* *The Quest:* Loop from 1 to 100. If divisible by 3 print `"Fizz"`, by 5 print `"Buzz"`, by both print `"FizzBuzz"`.


4. **Valid Anagram**
* *The Quest:* Check if two strings use the exact same characters in a different order (e.g., `"listen"` and `"silent"`).


5. **First Unique Character**
* *The Quest:* Find the very first character in a string that doesn't repeat anywhere else.


6. **Count Vowels and Consonants**
* *The Quest:* Scan a string and count how many vowels (`a, e, i, o, u`) are inside it.



---

## 📊 Category 2: The Array Mechanics

*These questions test if you know how to loop, slice, and keep track of memory variables.*

7. **Find the Maximum/Minimum Number**
* *The Quest:* Scan an array and pull out the absolute biggest or smallest score. (You coded this perfectly!)


8. **Two Sum**
* *The Quest:* Find two numbers that add up to a target value and return their positions. (The Level 1 Boss!)


9. **Remove Duplicates from an Array**
* *The Quest:* Take `[1, 1, 2, 2, 3]` and clean it up to just `[1, 2, 3]`.


10. **Move Zeroes**
* *The Quest:* Take an array like `[0, 1, 0, 3, 12]` and push all the zeros to the very end without messed up the order of the other numbers.


11. **Merge Two Sorted Arrays**
* *The Quest:* Combine `[1, 3, 5]` and `[2, 4, 6]` into one perfectly ordered array: `[1, 2, 3, 4, 5, 6]`.


12. **Find the Missing Number**
* *The Quest:* You are given an array containing $n-1$ integers from $1$ to $n$. Find the one missing number.


13. **Array Rotation**
* *The Quest:* Shift an array to the right by $k$ steps. E.g., `[1, 2, 3]` shifted by 1 becomes `[3, 1, 2]`.



---

## 🧩 Category 3: The Logic & Math Puzzles

*These are pure algorithm questions to see how your brain handles step-by-step math setups.*

14. **Fibonacci Sequence Generator**
* *The Quest:* Generate the sequence where each number is the sum of the two preceding ones ($0, 1, 1, 2, 3, 5, 8...$).


15. **Factorial of a Number**
* *The Quest:* Find the factorial of $n$ (e.g., $5! = 5 \times 4 \times 3 \times 2 \times 1 = 120$).


16. **Prime Number Checker**
* *The Quest:* Write a script to determine if a number is a prime number (only divisible by 1 and itself).


17. **Leap Year Checker**
* *The Quest:* Write the precise mathematical conditions to check if a year is a leap year.



---

## 🗃️ Category 4: The Storage Masters (Objects & Maps)

*These test your ability to count frequencies and map relationships.*

18. **Find the Majority Element**
* *The Quest:* Find the element in an array that appears more than $\lfloor n/2 \rfloor$ times.


19. **Character Frequency Counter**
* *The Quest:* Take a string and count exactly how many times *each* letter appears (e.g., `"apple"` $\rightarrow$ `{a:1, p:2, l:1, e:1}`).


20. **Intersection of Two Arrays**
* *The Quest:* Find the common numbers that exist in both of two separate arrays.
